A small Windows tray app that remaps the Copilot hardware key to Calculator, Notepad, Terminal, Explorer, Settings, or any .exe you pick.

Why this exists

Newer PCs replaced a useful key with Copilot. You should be able to spend that key on the app you actually open all day.

Any app, not an AI picker

This is a general remapper. Calculator is the default. Browse to any executable. ChatGPT is only an optional preset if you already have it installed.

No admin required

The remap uses a user-level keyboard hook and the official Win+Shift+F23 shortcut. Nothing is written to a scancode map. Uninstall is just quit plus cleanup.

Stays out of the way

Lives in the tray. Open settings, enable or disable the remap, or quit. Optional start at login. Settings live in AppData only.

Install in a minute

  1. Download the zip from the latest GitHub Release.
  2. Unzip and double-click BetterCopilotButton.exe.
  3. Leave Calculator selected, or pick another app.
  4. Turn Enable on. Press the Copilot key.

After it is running

  1. Use Test launch to confirm the target app.
  2. Optionally check Start at login.
  3. Optionally Add to Start menu or run install.ps1.
  4. Uninstall from the app, Apps settings, or uninstall.ps1. The Copilot key returns to normal when the app is not running.

How it works

Microsoft defined the Copilot key as Left Windows + Left Shift + F23. This app listens for that chord and opens your target instead.

1. Listen

A short state machine watches for Win, then Shift, then F23. Real Win and Shift keys are replayed if F23 does not arrive, so Start and Win+Shift shortcuts still work.

2. Launch or focus

If the target is already running, it is brought to the front. File Explorer always opens a new window. Settings uses the ms-settings: protocol.

3. Clean exit

Disable remap or quit and the hook is gone. No leftover kernel remap. That is why uninstall restores Copilot key behavior.

FAQ

Do I need Administrator?

No. The remap and start-at-login setting are per user. If a future Windows policy blocked hooks, the app would tell you instead of showing a surprise UAC prompt.

Why not use Windows Settings?

Windows 11 can remap the Copilot key to Copilot, Search, or a Store app. It cannot point the key at an arbitrary .exe such as Calculator or a portable tool. That is the gap this app fills.

The Copilot key still opens Copilot

Some laptops handle the key in firmware or a vendor driver, so Windows never sees Win+Shift+F23. Test launch can still work. Another remapper may also own the shortcut. See the README limitations section.

Is this an AI switcher?

No. It remaps one key to any program. The default example is Calculator. Optional presets include everyday Windows apps. One optional ChatGPT path exists only if that desktop app is already installed.

Does it collect data?

No telemetry, ads, or login. Settings are a JSON file in AppData.
